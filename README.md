# movies-list: Aplicação simples para exercitar testes unitários e CI/CD

Essa aplicação possui uma página para realizar consultas de nomes de filmes através da API pública **OMDb API**. Possui apenas uma rota para fazer uma requisição pelo nome do filme.

## Como baixar e configurar o projeto

Clone o repositório para sua máquina local

```bash
git clone https://github.com/juceilson/movies-list.git
```

Entre no repositório pelo terminal ou IDE e instale as dependências

```bash
npm install
```

Copie e cole o arquivo .env.example e renomeie para .env

Adiquira uma api key no site do https://www.omdbapi.com e coloque na variável do arquivo .env

## Como executar os testes e rodar o projeto

execute os testes rodando o script:

```bash
npm run test
```

Execute o projeto em modo desenvolvedor:

```bash
npm run dev
```
